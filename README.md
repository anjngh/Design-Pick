# Design Pick

A reusable design skill for choosing and applying visual styles to presentations and websites in Codex and Claude Code.

This package includes 80 design packs: 40 for presentations and 40 for websites.

## Install in Codex

1. [Download the installable skill ZIP](https://github.com/anjngh/Design-Pick/raw/refs/heads/main/design-pick-codex.zip).
2. Extract the ZIP. It contains a folder named `design-pick`.
3. Copy that folder to:
   - Windows: `%USERPROFILE%\.codex\skills\design-pick`
   - macOS/Linux: `~/.codex/skills/design-pick`
4. Start a new Codex conversation and invoke it with `$design-pick`.

## Install in Claude Code

Extract the same ZIP and copy its `design-pick` folder to:
- Windows: `%USERPROFILE%\.claude\skills\design-pick`
- macOS/Linux: `~/.claude/skills/design-pick`
